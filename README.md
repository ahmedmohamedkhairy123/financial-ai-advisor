# 🚀 Financial Advisor App
### AI-Powered Investment Strategy & Forecasting Tool

An intelligent financial planning application that analyzes your financial profile to provide personalized investment strategies and feasibility assessments using Google's Gemini AI.

## ✨ Features
- **AI-Powered Analysis**: Get personalized investment recommendations from Gemini AI
- **Multi-Step Form**: Comprehensive financial profile collection
- **Traffic Light System**: Visual feasibility assessment (Red/Yellow/Green)
- **Interactive Charts**: Portfolio allocation visualization
- **Responsive Design**: Works on all devices

## 🛠️ Tech Stack
- **Frontend**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Charts**: Recharts
- **AI**: Google Gemini API
- **Build Tool**: Vite
